2. Step-by-Step Instructions for VS Code
Prerequisites
Java Development Kit (JDK) installed.

Extension Pack for Java installed in VS Code.

Setup Steps
Create a Project Folder: Create a new folder on your computer (e.g., ChatApp). Open this folder in VS Code.

Create the Package Folder: Inside your project folder, create a new folder named exactly chat.

Create the Files:

Inside the chat folder, create chatserver.java. Paste the Server code there.

Inside the chat folder, create chatclient.java. Paste the Client code there.

Open Terminal: Go to Terminal -> New Terminal in VS Code.

Execution Steps (Important Order)
Compile the Code: In the terminal, type: javac chat/*.java

Run the Server FIRST: In the terminal, type: java chat.chatserver (A window titled "Server" will pop up. It will look like it's frozen; this is normal because it's waiting for a connection.)

Run the Client: Open a second terminal tab (+ icon in the terminal panel) and type: java chat.chatclient (A second window titled "Client" will pop up.)

Test the Chat: Type a message in the Client's text box and hit "Send." It will appear on the Server. Type in the Server box and hit "Send" to reply!
