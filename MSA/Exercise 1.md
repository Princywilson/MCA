# **Experiment: Multimedia Systems and Applications Lab**

## **Title:**

Editing Various Images (Image Restoration, Converting Colour Image to Grayscale and Vice Versa, and Adding Special Effects) Using Tools like Photoshop, GIMP and Flash

---

## **Aim:**

To study and perform image editing techniques such as image restoration, colour to grayscale conversion and vice versa, and to apply special effects to images using multimedia tools such as **Adobe Photoshop**, **GIMP**, and **Adobe Flash**.

---

## **Tools Required:**

* Computer system with multimedia software installed
* Adobe Photoshop
* GIMP
* Adobe Flash
* Sample colour and damaged images

---

## **Theory:**

Image editing is a fundamental concept in multimedia systems and applications. It involves modifying digital images to enhance their quality, correct defects, or create artistic effects. Image editing is widely used in photography, advertising, animation, web design, and film production.

**Image Restoration** is the process of improving the appearance of a damaged, blurred, or noisy image. It removes imperfections such as scratches, dust, noise, and blur using filters and correction tools.

**Grayscale Conversion** is the process of converting a colour image (RGB) into shades of grey. In grayscale images, each pixel carries only intensity information rather than colour information. It reduces image complexity and is commonly used in image processing and printing.

**Colourization** (Grayscale to Colour) involves adding colour to a grayscale image either manually or using automatic tools. This enhances visual appeal and improves interpretation.

**Special Effects** include adding filters, shadows, blurring, sharpening, embossing, contrast enhancement, and artistic effects to enhance the overall look of the image.

---

## **Procedure:**

### **Part A: Image Restoration using Photoshop / GIMP**

1. Open Adobe Photoshop or GIMP.
2. Click on **File → Open** and select a damaged or noisy image.
3. Use the **Clone Stamp Tool** or **Healing Brush Tool** to remove scratches and spots.
4. Apply **Noise Reduction Filter** to remove unwanted grain.
5. Adjust brightness and contrast using **Image → Adjustments → Brightness/Contrast**.
6. Use the **Sharpen Tool** to improve clarity.
7. Save the restored image using **File → Save As**.

---

### **Part B: Convert Colour Image to Grayscale**

1. Open the colour image in Photoshop or GIMP.
2. Go to **Image → Mode → Grayscale** (in Photoshop)
   OR
   **Image → Mode → Grayscale** (in GIMP).
3. Confirm the conversion when prompted.
4. Observe that the image now contains only shades of grey.
5. Save the grayscale image.

---

### **Part C: Convert Grayscale Image to Colour**

1. Open the grayscale image.
2. Change the mode to **RGB Colour Mode**.
3. Use the **Brush Tool** and select desired colours.
4. Create a new layer for colouring.
5. Carefully apply colours to different parts of the image.
6. Adjust blending mode and opacity for natural appearance.
7. Save the colourized image.

---

### **Part D: Adding Special Effects**

1. Open an image in Photoshop, GIMP, or Flash.
2. Apply different filters such as:

   * Blur
   * Sharpen
   * Emboss
   * Sepia Tone
   * Artistic Filters
3. Use **Layer Styles** to add:

   * Drop Shadow
   * Outer Glow
   * Gradient Overlay
4. Adjust saturation and hue using **Hue/Saturation Tool**.
5. Preview changes and finalize the effect.
6. Save the final edited image.

---

## **Observations:**

* Grayscale conversion reduces colour data and highlights texture and contrast.
* Colourization enhances visual appeal.
* Special effects improve artistic quality and presentation.
