## Multimedia Systems and Applications Lab

### Experiment 3: Creating Three-Dimensional Models and Animations Using Blender, 3DS Max, and Unity

---

## **Aim**

To design and develop three-dimensional (3D) models and create animations using modern multimedia development tools such as **Blender**, **Autodesk 3ds Max**, and **Unity**, and to understand the fundamental concepts of 3D modeling, texturing, lighting, rendering, and animation in multimedia systems.

---

## **Procedure**

### **Step 1: Introduction to 3D Modeling Environment**

1. Open the 3D modeling software (Blender / 3DS Max).
2. Understand the workspace layout including:

   * Viewport
   * Timeline
   * Properties panel
   * Object hierarchy
3. Learn basic navigation controls such as:

   * Rotate view
   * Zoom in/out
   * Pan across scene

This step helps in familiarizing with the interface and understanding how 3D objects are viewed and manipulated in a virtual environment.

---

### **Step 2: Creation of Basic 3D Objects**

1. Add primitive shapes such as:

   * Cube
   * Sphere
   * Cylinder
   * Plane
2. Use transformation tools:

   * **Move (Translation)**
   * **Rotate**
   * **Scale**
3. Modify object dimensions using edit mode.
4. Apply mesh editing techniques such as:

   * Extrusion
   * Loop cut
   * Subdivision
   * Face editing

Through this step, a simple 3D model such as a table, chair, or house structure can be created.

---

### **Step 3: Applying Materials and Textures**

1. Open the material editor panel.
2. Assign different materials to objects.
3. Adjust:

   * Color
   * Roughness
   * Metallic properties
4. Apply texture images to enhance realism.
5. Perform UV mapping to correctly wrap textures onto the 3D surface.

This step improves the visual appearance of the 3D model and gives it a realistic look.

---

### **Step 4: Lighting and Camera Setup**

1. Add different types of lights:

   * Point light
   * Directional light
   * Spot light
   * Area light
2. Adjust light intensity and position.
3. Insert a camera into the scene.
4. Set camera angle and focal length.
5. Preview the scene from the camera view.

Proper lighting and camera positioning enhance depth, shadows, and realism in the 3D environment.

---

### **Step 5: Creating Animation**

1. Open the timeline panel.
2. Select the object to animate.
3. Set keyframes for:

   * Location
   * Rotation
   * Scale
4. Move to another frame and change object position.
5. Insert another keyframe.
6. Play the animation to observe motion.

Example:

* Animate a bouncing ball.
* Rotate a cube continuously.
* Move a car model from one point to another.

Animation works on the principle of keyframes and interpolation between frames.

---

### **Step 6: Rendering the Scene**

1. Set render engine (Eevee / Cycles in Blender).
2. Adjust resolution settings.
3. Select output format (PNG / JPEG / MP4).
4. Render image or animation.
5. Save the final output file.

Rendering converts the 3D scene into a 2D image or video format.

---

### **Step 7: Importing into Unity (Optional Integration)**

1. Export the model in FBX or OBJ format.
2. Open Unity project.
3. Import the model into Assets panel.
4. Add the model to the scene.
5. Apply materials and physics if required.
6. Play the scene to test animation inside Unity.

This step demonstrates integration of 3D models into real-time applications and game environments.

---

## **Result**

The three-dimensional model was successfully created using Blender/3DS Max. Materials and textures were applied to enhance visual quality. Lighting and camera positioning were adjusted to improve scene composition. Animation was implemented using keyframe techniques, and the final output was rendered successfully. The model was optionally imported into Unity to verify real-time interaction and animation functionality.

Thus, the experiment helped in understanding the practical implementation of 3D modeling, texturing, lighting, animation principles, and rendering techniques used in multimedia systems and applications.

---

## **Output**

* A completed 3D model (e.g., house / bouncing ball / rotating cube).
* Rendered image file (.png / .jpg).
* Rendered animation video file (.mp4).
* Unity project file containing imported 3D asset.
* Smooth animation created using keyframes.
* Properly lit and textured 3D scene.
